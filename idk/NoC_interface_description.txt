NoC interface

Transaction begin:
-Transaction beggins when one of the lines brings up valid signal.
-Based on arbiter logic apropriate line is picked for maintaining comunication. Node changes state from idle to active transaction. Current grant is saved to internal memory.
Active signal on particular line is high. The rest ov the lines are in unactive state.
-Transaction takes place until apropriate operation code is sent. Up to this operation internal multiplexer is latched to particular NoC line.
-Afterwards communication is returns to idle state end expects next line to activate.

Transaction process (in a block);
- When state transitions to "NoC_Transaction" assert active = '1'
- Connect input pointed by grant to an internal signal via combinatoric logic
- Connect output pointed by grant to an internal signal via combinatoric logic
- to the rest of inputs / outputs default values are assigned.
- Await an operation
